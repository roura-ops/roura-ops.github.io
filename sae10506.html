Site vitrine
Capgemini

HTML CSS Canva Google Docs / Drive 5 personnes Plusieurs semaines

Description & objectifs

Créer un site web complémentaire à celui de Capgemini, destiné aux élèves de 3ème en recherche de stage. Le site doit être clair, adapté à un public jeune, respecter les contraintes visuelles de l'entreprise, et couvrir les différents secteurs d'activité et domaines de Capgemini.

Compétences mobilisées

  • Conduire un projet
  • Travailler dans un équipe informatique

Travail en groupe

Groupe de 5. organiser les taches par compétences : 2 personnes du groupe et moi avons fait les recherches, chacun sur la partie où il se sentait le plus à l'aise. une autre personne a structuré le document. Pour le site, on s'est mis d'abord sur les couleurs via un root CSS partagé, puis chacun a codé sa page en version desktop et mobile.

Ma contribution individuelle

Collecter les informations sur la partie carrières de Capgemini, puis reformuler dans un langage simple et accessible pour des collégiens. Pour le site, coder la page d'accueil et la barre de navigation, en respectant les couleurs définies dans le root CSS commun.
